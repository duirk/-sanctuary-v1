# -sanctuary-v1
Proyecto Génesis: Modelado Matemático del ADN
Este repositorio contiene la formalización
teórica, esquemas y análisis espectrales 
desarrollados por Nadal Ferrá en la intersección entre la biología molecular, 
la geometría vectorial y el álgebra lineal. Aquí se exploran los puentes analíticos 
que permiten descifrar la estructura y periodicidad de la doble hélice mediante herramientas 
matemáticas avanzadas.
